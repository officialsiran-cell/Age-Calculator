# ⚡ Cyber HUD - Modern Age Calculator

A sleek, futuristic **Tony Stark / Cyberpunk-inspired** Age Calculator web application built with vanilla **HTML5, CSS3, and JavaScript**.

## 🌟 Key Features
- 🚀 **Futuristic UI:** Deep space dark background featuring neon cyan luminescent glow effects.
- 🎯 **Precise Calculation:** Real-time chronological age breakdown into exact Years, Months, and Days.
- 📱 **Fully Responsive:** Smooth scaling across desktop monitors, tablets, and mobile viewports.
- ⚡ **Zero Dependencies:** Pure vanilla JavaScript logic with no heavy external frameworks.

---

## 🛠️ Tech Stack & Architecture
- **HTML5:** Semantic element structure (`<main>`, `<input type="date">`, `<button>`).
- **CSS3:** Custom modern box-shadows, CSS Flexbox centering, and dynamic hover transitions.
- **JavaScript (ES6):** Native `Date()` object manipulation, calendar-month leap calculations, and DOM manipulation.
